How this simulator follows the rules
  • Rules come from the official task description, version 4. The random number generator reproduces the spec’s 100 test values for seed 12345.
  • The official sample.ant and step-by-step dump files were never available to check against, so round-by-round agreement with the judges’ simulator is untested. “Copy state dump” writes a dump in the same field order for comparison.
  • Generated worlds follow section 3.1. Rock shapes are my own choice, since the spec does not define them.
  • Hex cells are drawn as squares, with odd rows shifted half a cell right, exactly as in the world file.
  • The POV views show what a colony can sense: each living ant’s cell and its six neighbours. Fogged cells keep terrain and your own markers.
